# Απομακρυσμένη Διαχείριση Υπολογιστών μέσω TCP (Java Server)

Αυτό το έργο περιλαμβάνει έναν **διακομιστή (Server)** υλοποιημένο σε γλώσσα **Java**, ο οποίος επιτρέπει την **απομακρυσμένη διαχείριση υπολογιστών** μέσω σύνδεσης **TCP**. Περιλαμβάνει και **απλό γραφικό περιβάλλον χρήστη (GUI)** για ευκολία στη χρήση.

## Λειτουργίες

1. ✅ Ο χρήστης μπορεί να επιλέξει όσους υπολογιστές επιθυμεί για αποστολή εντολής ή ενεργοποίηση μέσω Wake-on-LAN (WOL).
2. ⚙️ Υπάρχει δυνατότητα επιλογής ανάμεσα σε 4 εντολές:
   - `Echo` (έλεγχος επικοινωνίας)
   - `Shutdown` (κλείσιμο)
   - `Restore` (επαναφορά)
   - `Restart` (επανεκκίνηση)
3. 🔍 Υπάρχει δυνατότητα ελέγχου των υπολογιστών που είναι ενεργοί με τη λειτουργία `Check PCs`.

## Προϋποθέσεις

- Java JDK 8 ή νεότερη
- Android Studio (Τo run)
- Υποστήριξη TCP στα συστήματα-πελάτες
- Ενεργοποιημένο Wake-on-LAN (για χρήση WOL)

## Εκτέλεση

1. Κάντε compile το αρχείο `Server.java`:
```bash
javac Server.java
Εκκινήστε τον server:
java Server
```
Αλληλεπιδράστε με το GUI (μεσο της εφαρμογής android studio) για να διαχειριστείτε τους υπολογιστές.
